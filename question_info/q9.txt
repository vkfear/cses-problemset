Bit Strings

Your task is to calculate the number of bit strings of length n.
For example, if n=3, the correct answer is 8,
because the possible bit strings are 000, 001, 010, 011, 100, 101, 110, and 111.

INPUT

The only input line has an integer nnn.

Example

Input:  3
Output:  8

Approach:

We need to construct a string of length N where each character can either be '0' or '1'. 
Thus, for every position we have 2 choices, and since there are N positions in total, 
the number of possible bit strings is 2^N.

Since 2^N can grow very large, the answer is taken modulo (10^9 + 7). 
This can be efficiently computed using Binary Exponentiation, which reduces 
the time complexity from O(N) to O(log N).
